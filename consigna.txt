01  Objetivo

El objetivo de esta actividad es aplicar los fundamentos de bases de datos y modelado para gestionar eficazmente el conjunto de datos de reseñas de vinos. Los estudiantes aprenderán a diseñar y estructurar bases de datos relacionales, utilizarán el lenguaje SQL para realizar consultas complejas que extraigan información específica y relevante del conjunto de datos, y explorarán técnicas de análisis multidimensional para obtener perspectivas detalladas sobre las características y tendencias de los vinos basadas en múltiples dimensiones. Además, se enfocarán en la administración eficiente de la base de datos, asegurando la integridad y disponibilidad de los datos para su análisis continuo.

03  Consigna abierta

    1. Diseño de la base de datos:
        ◦ Crear un modelo de base de datos relacional que refleje adecuadamente la estructura del conjunto de datos de reseñas de vinos, considerando entidades, atributos y relaciones relevantes.
        ◦ Definir esquemas de tablas que permitan almacenar y relacionar la información de manera eficiente.
    2. Implementación y gestión de la base de datos:
        ◦ Utilizar un sistema de gestión de bases de datos (SGBD) como MySQL, PostgreSQL o SQLite para implementar el diseño de la base de datos.
        ◦ Asegurar la integridad de los datos mediante la definición de restricciones y la gestión de transacciones.
    3. Consultas SQL avanzadas:
        ◦ Desarrollar consultas SQL complejas que respondan a preguntas específicas sobre el conjunto de datos, como la cantidad de vinos por país, las variedades más comunes en una región específica, o el precio promedio por punto de calificación.
    4. Análisis multidimensional:
        ◦ Realizar análisis multidimensional para explorar las características de los vinos a través de múltiples dimensiones como país, variedad, precio y puntuación.

Recursos:
    • Conjunto de datos de reseñas de vinos (winemag-data-130k-v2.csv).
    • Sistema de gestión de bases de datos (MySQL, PostgreSQL, SQLite).

 

04  Formato entregable

En este trabajo práctico deberá hacer entrega de tres archivos:

Script SQL: Un archivo que contenga todos los comandos SQL utilizados para crear las tablas, definir las restricciones de integridad, insertar datos y realizar consultas avanzadas en la base de datos de MySQL. Este script debe estar bien comentado para explicar cada paso y facilitar la comprensión del proceso. Incluir comentarios pertinentes que permitan la comprensión del mismo. 

Informe técnico: Un documento que describa detalladamente el proceso llevado a cabo, incluyendo:
    • Una explicación del modelo de base de datos relacional diseñado, con el esquema de las tablas, relaciones entre ellas y las decisiones de diseño tomadas.
    • Ejemplos significativos de consultas SQL utilizadas, junto con los resultados obtenidos y su interpretación.
    • Discusión sobre los desafíos enfrentados y cómo fueron abordados durante el trabajo con la base de datos MySQL o similar.
    • Conclusiones sobre los resultados obtenidos y posibles áreas para investigaciones futuras en el contexto del análisis de datos de vinos.

Diagrama de la base de datos: Un diagrama visual del modelo de base de datos relacional diseñado en formato PDF. Este diagrama proporcionará una representación clara de las tablas, los atributos y las relaciones entre ellas, facilitando la comprensión de la estructura de la base de datos implementada. En el mismo deben estar claramente indicados:
    • Entidades
    • Atributos de las entidades
    • Relaciones
    • Claves primarias y foráneas
    • Cardinalidad

Cuerpo del informe:
    • Tipo de letra: Preferiblemente Times New Roman o Arial.
    • Tamaño de letra: 12 puntos para texto principal, 14 puntos para títulos principales.
    • Interlineado: 1.5 líneas para el cuerpo del texto.
    • Márgenes: Ajustar a 2.5 cm en todos los lados.
    • Sangrías: Utilizar sangría de 1.27 cm. para el inicio de cada párrafo.
    • Encabezado y pie de página:
            ▪ Encabezado: Incluir el título del informe o el nombre del proyecto.
            ▪ Pie de página: Número de página y otra información relevante, como el nombre del autor o la fecha.

Otros aspectos significativos:
        • Numeración de páginas: Iniciar numeración en la página del índice.
    • Formato de títulos y subtítulos: Utilizar negrita para títulos y cursiva para subtítulos.
    • Referencias: Si es necesario, seguir el formato APA o el indicado por la institución.
    • Anexos: Incluir al final del informe si es necesario.
